# Asterisked bounds and their replays (teorth/optimizationproblems)

This page lists every bound that carries the asterisk, in the README table or on a constant page, and the independent replays posted for it in the pull requests and issues of [teorth/optimizationproblems](https://github.com/teorth/optimizationproblems). It records who posted what. It does not certify any bound, and it adds or removes no asterisk. Under [CONTRIBUTING](https://github.com/teorth/optimizationproblems/blob/main/CONTRIBUTING.md), taking an asterisk off needs a second party; this page is meant to make that easier to see.

Snapshot: main at commit [87b4ebb](https://github.com/teorth/optimizationproblems/commit/87b4ebbd426ff8db597a2004cc45da17903bdcf2) (28 October 2026); pull requests and issues read on 5 November 2026 (#270 to 09:50 UTC).

## Summary

That is 66 starred rows on constant pages, and 35 starred cells in the README table. Of the 25 rows in (a), 12 are in pull requests that remove the asterisk and already have a second party's confirmation in the thread: [#235](https://github.com/teorth/optimizationproblems/pull/235) (5 rows), [#242](https://github.com/teorth/optimizationproblems/pull/242) (3 rows), [#249](https://github.com/teorth/optimizationproblems/pull/249) (2 rows), [#292](https://github.com/teorth/optimizationproblems/pull/292) (2 rows).

## How to read the tables

- Row: the constant page and the reference key of the row. Claimant: the account that added the row, and the source when it is someone else's work.
- A replay is a comment, pull request or issue by someone other than the claimant that says they recomputed the bound from the certificate or from the page's description with their own code, or rebuilt a formal proof, and gives the result. Partial checks are marked partial. Recomputations by a row's submitter of someone else's construction are listed and marked.
- Pull requests: the merged one that added the row, then the open ones that change the row or would replace its README cell.
